# Spanish Verbs A1–A2 — PWA

Offline PWA for practicing Spanish verbs at A1–A2 level. Includes Learn, Review, Dictionary, Present, Pretérito Indefinido and Future, with English translations.

## Run

Host the contents on HTTPS (for example GitHub Pages) or use localhost.

### iPhone
Open the HTTPS app in Safari → Share → Add to Home Screen → Add.

### Android
Open the HTTPS app in Chrome → menu → Add to Home screen / Install app.

After the first load, the app can work offline using the Service Worker.
